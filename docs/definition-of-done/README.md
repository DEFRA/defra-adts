## Purpose

This folder exists to signpost the agreed Definition of Ready for the ADTS team.

A story should only be brought into sprint when it is clear enough for the team to understand, estimate, build and test without needing major discovery during the sprint.

For the latest agreed checklist, refer to the SharePoint link above.
